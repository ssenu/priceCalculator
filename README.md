# 시제계산기

매장 현금 시재 점검용 Windows 데스크톱 앱 (PyQt6).

## 기능
- 지폐/동전(5만·1만·5천·1천·500·100·50원) 매수 입력 → **금고(=단위×매수 합)** 자동 계산
- **데이터**(있어야 할 금액) 수동 입력 → **차액(=금고-데이터, 음수 가능)** 자동 계산
- 저장 시 메모·이름·근무시간(오전/오후1/오후2/야간/사장님) 기록, 시간 자동 저장 → JSON 누적
- 내역: 최신순 요약 카드, 체크박스로 선택 삭제/인쇄
- 인쇄/PDF/이미지(PNG) 출력 — A4 한 쪽에 8건, 미리보기 제공, 출력 후 선택 삭제 옵션
- 입력 편의: Tab/Enter로 다음 칸 이동, 저장해도 입력값 유지

## 데이터 위치
`%APPDATA%\시제계산기\records.json` (자동 백업 `.bak`, 원자적 저장)

## 개발 (uv)
```bash
uv sync          # 의존성 설치
uv run python main.py   # 실행
```

## 빌드 (exe)
```bash
build.bat        # dist\시제계산기.exe 생성 (onefile)
```
exe는 어디에 두어도 동작하며, 데이터는 %APPDATA%에 저장됩니다.
