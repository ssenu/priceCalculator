# 💵 시제계산기

매장·카페에서 **근무 교대 시 현금 시재(시제)를 빠르고 정확하게 점검**하는 Windows 프로그램입니다.
지폐·동전 매수만 입력하면 금고 금액과 차액을 자동으로 계산하고, 기록을 저장·인쇄할 수 있습니다.

## ✨ 주요 기능

### 시재 자동 계산
- 5만·1만·5천·1천·500·100·50원 **매수만 입력**하면 **금고(= 단위 × 매수 합계)** 자동 계산
- POS 등 **데이터 금액**을 입력하면 **차액(= 금고 − 데이터)** 자동 표시 (부족하면 빨강, 남으면 초록)
- **이전 근무자의 차액**을 화면에 함께 표시 → 인수인계가 편함
- 숫자 입력 시 천 단위 콤마 자동, Tab·Enter로 다음 칸 이동

### 저장 · 메모
- **이름·근무시간**(오전/오후1/오후2/야간/사장님)과 함께 저장, 시간은 자동 기록
- 근무시간 기본값이 **현재 시각대에 맞게 자동 선택**(예: 오후 2시 → 오후1)
- 자주 쓰는 **이름은 버튼으로 저장**되어 클릭 한 번으로 입력
- 메모 기본값이 **차액과 이전 근무자 차액의 차이**를 자동으로 제안

### 내역 · 인쇄
- 저장한 기록을 **날짜별로 묶어 카드로** 보기 (최신순)
- 체크해서 **선택 삭제** 또는 **인쇄**
- **인쇄 / PDF / 이미지(PNG)** 로 출력 — A4 한 장에 8건, 미리보기 제공
- 출력한 내역을 바로 삭제하는 옵션

### 편의 · 보안
- 창 크기에 맞춘 **화면 확대/축소(＋ / －)**
- 다른 창 위에 **항상 고정**(📌) 기능
- **관리자 비밀번호**를 설정해 내역 삭제·인쇄를 보호

## 💾 데이터 저장 위치

모든 기록은 아래 폴더에 자동 저장됩니다. (백업하려면 이 폴더를 복사하세요.)

```
%APPDATA%\시제계산기\
```

- `records.json` : 시재 기록 (자동 백업본 `.bak` 포함, 안전 저장)
- `settings.json` : 비밀번호·화면 배율 등 설정

## 🛠 직접 빌드하기 (개발자용)

```bash
uv sync                 # 의존성 설치
uv run python main.py   # 실행
build.bat               # exe 빌드 → dist\시제계산기.exe
```

Python + PyQt6 / PyInstaller(onefile)로 빌드됩니다.
